# Как выложить на GitHub Pages

Статичная версия считает песни для всех дат заранее и работает без сервера.

1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта (папку `node_modules` не загружайте).
2. В репозитории: Settings → Pages → Source: **GitHub Actions**.
3. Готово: при каждом изменении в ветке `main` сайт пересобирается сам (файл `.github/workflows/pages.yml`).
   Адрес будет вида `https://ваш-логин.github.io/имя-репозитория/`.

Собрать вручную: `npm ci`, затем `npm run build:static` — готовый сайт появится в папке `static-dist/`.
Ссылка на результат работает так же: `.../?date=1985-06-12`.

База зафиксирована на дату сборки: после пересборки в неё попадают новые дни и все правки данных.
